# How metablock works?

## 1. 构造可逆映射

对于一般的 FLOW 模型, 其每一层的功能用下式定义:

$$
h = H(x)
$$

**规定:**

**假如** 按 **某种规则** 将 $x$ 拆分为两部分, 记为 $x_{part1}$, $x_{part2}$, 则按 **同样的规则** 将 $h$ 拆分为两部分, 记为 $h_{part1}$, $h_{part2}$

**则** 满足:
$$
h_{part1} = H(x_{part1})\\
h_{part2} = H(x_{part2})
$$

该函数的内部过程如下:
>
> 1. $x$ (shape = (B, \*\_,D)) 拆分为 $x_{part1}$, $x_{part2}$
>
>> ```python
>> x1 = x[:,:,...,0:d]
>> x2 = x[:,:,...,d: ]
>> ```
>
> 2. 利用 $x_{part1}$, $x_{part2}$ 计算 $h_{part1}$, $h_{part2}$.
>
>> 构造 $H(x_i) = e^{\gamma(x_{i-1})} \odot x_i + \beta (x_{i-1})$
>>
>> *(特别地, 当 i=1 时, 退化为 $H(x_1) = x_1$)*
>>
>> 则有:
>> $$
>> h_1 = H(x_1) = x_1\\
>> h_2 = H(x_2) =e^{\gamma(x_1)} \odot x_2 + \beta (x_1)
>> $$
>
> 3. 从 $h_{part1}$, $h_{part2}$ 拼接为 $h$
>
>> ```python
>> h = torch.stack([h1,h2], dim = -1)
>> # h1 = h[:,:,..,0:d]
>> # h2 = h[:,:,..,d: ]
>> ```

## 2. 可逆映射的逆运算

计算 $x = H^{-1}(h)$ 时, 依照如下方式:

将 $h$ 依照 **划分规则** 划分为 $h_{part1}$, $h_{part2}$.

由于 $h_1 = x_1$, 可以直接得到 $x_1$

对 $h_2 =e^{\gamma(x_1)} \odot x_2 + \beta (x_1)$ 移项, 得到:

$$

$$

代入 $h_1 = x_1$, 有:
$$
x_2 = \frac{h_2-\beta (h_1) }{e^{\gamma(h_1)}}
$$

得到 $x_1$ 和 $x_2$ 后, 依照 **划分规则**, 拼接得到 $x$

## 3. TarFlow 对上式的一般化扩展

**扩展部分:**

1. $x$ 划分为更多部分

2. 在 `1` 的基础上, 假设 $x$ 的 **每一维** 都划分为一部分, 则上式可扩展为:

$$
h_1 = x_1\\
h_2 = e^{\gamma(x_1)} \odot x_2 + \beta (x_1) \\
h_3 = e^{\gamma([x_1,x_2])} \odot x_3 + \beta ([x_1,x_2]) \\
\dots\\
h_D = \dots
$$

也即将 $x$ 使用两个函数 $\gamma(\cdot)$ 和 $\beta(\cdot)} **按行** 计算, 每一行的计算结果仅和*自身*及*其前面的所有行*相关

这种 **按行** 计算的特点, 很容易通过 **注意力机制** 实现

```python
h = attention(x, mask = 下三角矩阵)
# 宏观上, h和x形状相同, 且在下三角阵的作用下, h的第i行仅和x的前i行相关
# 因此, 上式等效于 γ 或 β.
# 因此, 使用两个 attention 分别表示 γ 或 β 即可
# 在实践中, 可以输出一个长度翻倍的h矩阵, 拆成两部分,分别做γ 或 β,减少计算压力
```
